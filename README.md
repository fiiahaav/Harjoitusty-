# Harjoitustyö - Sanatarkastaja

Projektissa toteutetaan suomenkielinen kirjoitusvirheiden korjaaja, joka hyödyntää Damerau-Levenshtein-etäisyyttä löytääkseen käyttäjän kirjoittamalle sanalle lähimmät oikeinkirjoitusvaihtoehdot.

## Projektin käynnistysohjeet
Kloonaa repositio koneellesi ja siirry projektikansioon omalla koneellasi

Asenna riippuvuudet, projektissa käytetään poetrya 

`poetry install`

Projektin käyttöliittymä on vasta komentirivitasolla, joten käynnistä ohjelma projektin juurikansiosta:

`poetry run python3 src/main.py`


Sovelluksen yksikkötestejä pääsee ajamaan komennolla:

`poetry run pytest`
